# Агент технической поддержки
Python 3.12

Помощник в поиске ответов на вопросы клиентов по базе знаний.

Веб приложение с формой ввода клиентского запроса. Для поиска ответа используется подход RAG. 
Сначала выполняется поиск релевантных документов в векторной базе данных, затем формируется ответ при помощи большой 
языковой модели. После получения ответа есть возможность оставить обратную связь по ответу, которая будет сохранена
в базу данных для дальнейшего анализа работы приложения.

## Разворачивание проекта:

Создаем файл `.env` на основе файла `.env.dist`: `touch .env && cat .env.dist > .env`

Запускаем команду: `make run-app`

В процессе запуска будут подняты следующие сервисы:

- векторная база данных qdrant
- реляционная база данных postgresql, также применятся миграции, чтобы в базе была актуальная схема данных
- векторная база данных наполнится данными из базы знаний
- запустится веб приложение на 5000 порту, в котором можно будет писать запросы

**! Важный момент !** Чтобы наполнить векторную базу данных значениями, нужен доступ к какому-либо конфлюенсу. Либо, просто
поднять контейнер с qdrant и наполнить его своими данными (не обязательно из конфлюенса), либо в `.env` файле указать
доступы к уже имеющемуся инстансу qdrant, далее запустить проект и писать запросы. Ответы будут отдаваться только если 
векторная база данных наполнена.

## Работа с миграциями БД

### Создание миграции
Выполняем команду `alembic revision -m "migration name"`, после ее выполнения в `alembic/versions` появится новый файл.
В новом файле пишем SQL запрос миграции.

### Запуск миграции
Выполняем команду `alembic upgrade head`

### Прочие команды
Смотри документацию https://alembic.sqlalchemy.org/en/latest/tutorial.html#create-a-migration-script
